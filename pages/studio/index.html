程序每轮抽取一次概率，命中后自动朗读回复中的一小段，其余内容保留文字 默认 20%，命中后自动执行；可与 LLM 自主语音一起开启，同轮共用去重 开启后支持 [语气:温柔]、[轻笑]、[耳语]、[唱歌]、[停顿] 和工具 instruction。关闭时忽略动态控制，使用默认语气，聊天文字隐藏控制标记 需要启用随机语音和动态语调；开启自适应时可在弹窗中一并启用
单独设为 0% 可关闭该场景的随机语音，LLM 仍可自主调用语音工具 默认 90 秒；随机语音与 LLM 工具共享间隔，同轮片段可连续发送，设为 0 可关闭间隔 先发对应文字，再单独发纯语音，避免平台吞掉混合消息 模型通过语音工具自主选择朗读内容；语音回合使用完整回复处理，文字支持普通发送、AstrBot 默认分段和分段插件 默认让带引用的回复保持文字；开启后保留引用正文并独立发送语音，被引用的原消息不参与合成 官方默认账号上限 1000 字；提升上限前请确认账号权限。超限片段保持文字 达到数量或容量上限时清理最旧成品，参考录音保留到手动删除 默认 256 MiB；待发送音频在发送后清理，参考录音单独保留
