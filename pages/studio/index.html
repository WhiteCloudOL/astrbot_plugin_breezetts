C++ 合成参数

聊天发送与动态语调多段合成统一使用无损 PCM/WAV。PCM 走原生表单，WAV/MP3 走 JSON 音频接口；上传参考音色会自动注册内存缓存。
采样参数及最大帧数为 0 时沿用服务端默认值。分段字符数 -1 跟随服务端，0 关闭服务端分段；每秒约 12.5 帧。长文本建议保留分段。

聊天与运行

命令：/breezetts 想说的话
别名：/btts、/语音合成

程序每轮抽取一次概率，命中后自动朗读回复中的一小段，其余内容保留文字 默认 20%，命中后自动执行；可与 LLM 自主语音一起开启，同轮共用去重 开启后允许分段语气、当前平台原生标签和工具 instruction；推荐按语境使用，也可不加。固定平台使用精确情绪值，自由平台可描述细致表演。关闭时忽略动态控制，聊天文字隐藏已识别标记 需要启用随机语音和动态语调；开启自适应时可在弹窗中一并启用

语音提示词

推荐 LLM 按语境添加语气或标签，也可以不加。点击编辑完整模板，使用变量插入当前平台的规则与标签表。

单独设为 0% 可关闭该场景的随机语音，LLM 仍可自主调用语音工具 默认 90 秒；随机语音与 LLM 工具共享间隔，同轮片段可连续发送，设为 0 可关闭间隔 先发对应文字，再单独发纯语音，避免平台吞掉混合消息 SnowLuma 会四舍五入上报语音时长。开启后只在聊天语音末尾补静音至整数秒，减少尾音被提前结束的风险 模型通过语音工具自主选择朗读内容；语音回合使用完整回复处理，文字支持普通发送、AstrBot 默认分段和分段插件 默认让带引用的回复保持文字；开启后保留引用正文并独立发送语音，被引用的原消息不参与合成 默认上限 1000 字；请按所选模型的实际限制调整。超限片段保持文字 达到数量或容量上限时清理最旧成品，参考录音保留到手动删除 默认 256 MiB；待发送音频在发送后清理，参考录音单独保留

名称限字母、数字、短横线或下划线；填写后保存 .breeze 文件，同名会覆盖音色，请核对名称。
描述最多 4096 个 UTF-8 字节；元数据最多 32 项，每个值最多 1024 字节。移除已有字段可删除对应键，或将值设为 null；这些信息不改变合成声音。
